# iceclimber-lite 🧗

极简登冰山街机小游戏，纯 Python 标准库，零依赖。

## 玩法

- 你在一条 1 格宽的竖直冰缝底部，目标是爬到山顶（`y <= 3`）。
- `w` 跳（2 格）、`u` 向上挥锤、`j` 向下挥锤、`q` 退出。
- 冰缝里随机生成 2~4 个**冰塞子**挡路：贴到塞子底下按 `u` 敲碎（+100 分），再跳过去。
- **Topi** 会在冰缝里上下巡逻：撞上就掉一条命（共 3 条）；贴脸时用锤子拍它（+500 分）。
- 登顶 +1000 分。

### 小巧思：攀附（chimneying）

在冰缝里如果左右两侧都是真冰壁，玩家会**攀附住不下坠**——现实里攀岩抱石也这么过窄缝。
竖井生成时保证互不相邻、不贴边，所以攀附永远可用；地图边界外不算冰壁，
沿着山体外侧偷爬上山是行不通的，老老实实敲塞子吧。

## 运行

```bash
python3 -m iceclimber_lite            # 交互模式（需要终端，回车确认每一步）
python3 -m iceclimber_lite --auto --seed 42            # 无头自动演示
python3 -m iceclimber_lite --auto --seed 42 --verbose  # 打印棋盘
```

图例：`P` 玩家，`T` Topi，`#` 冰，`.` 空。

## 诚实局限

- **无实时键盘输入**：交互是回合制（每行一个命令），不是真正的实时动作游戏；
  实时版需要 curses 接按键事件。
- 关卡是竖井一维结构，没有原版左右两座山的横向玩法；敌人只有 Topi 一种。
- `--auto` 的 AI 很强（贴脸先手必拍中 Topi），演示几乎不掉命——人类手玩时 Topi 威胁大得多。
- 无音效、无最高分存档、无难度分级；Python 3.10+。
